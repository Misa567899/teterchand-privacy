مرور کلی

تترچند یک افزونه مرورگر کروم است که قیمت‌های عمومی بازار تتر (USDT) به تومان را نمایش می‌دهد. این افزونه برای کارکرد خود به حساب کاربری، اطلاعات هویتی یا داده‌های حساس دسترسی ندارد.

ما ادعا نمی‌کنیم که افزونه هیچ درخواست شبکه‌ای انجام نمی‌دهد یا هیچ فراداده‌ای منتقل نمی‌شود؛ بخش «درخواست‌های شبکه‌ای» این موضوع را دقیق توضیح می‌دهد.

داده‌هایی که به‌صورت محلی ذخیره می‌شوند

افزونه آخرین قیمت‌های دریافت‌شده و اطلاعات کش را به‌صورت محلی روی دستگاه شما و با استفاده از chrome.storage.local نگه می‌دارد:

  • آخرین مقادیر قیمت تتر/تومان که از Wallex دریافت شده‌اند.
  • زمان دریافت یا انقضای کش، تا افزونه بدون درخواست تکراری داده‌های به‌روز را نمایش دهد.
  • این داده‌ها فقط در پروفایل مرورگر شما باقی می‌مانند؛ توسعه‌دهنده سروری برای جمع‌آوری آن‌ها ندارد.

درخواست‌های شبکه‌ای

برای نمایش قیمت‌ها، افزونه از طریق HTTPS درخواست‌هایی به API عمومی Wallex ارسال می‌کند. این درخواست‌ها فقط برای دریافت قیمت‌های عمومی بازار انجام می‌شوند.

  • درخواست‌ها با HTTPS و به دامنه API والکس ارسال می‌شوند.
  • مانند هر درخواست اینترنتی، فراداده‌های فنی استاندارد مانند آدرس IP، زمان درخواست و اطلاعات عامل کاربر می‌تواند برای Wallex قابل مشاهده باشد.
  • تترچند از این درخواست‌ها برای ردیابی، تبلیغات یا تحلیل رفتار استفاده نمی‌کند و داده تحلیلی ارسال نمی‌کند.

مجوزهای افزونه

storage

برای ذخیره محلی قیمت‌ها و اطلاعات کش با chrome.storage.local.

دسترسی میزبان

دسترسی به دامنه API والکس، فقط برای دریافت قیمت‌های عمومی بازار از طریق HTTPS.

سرویس‌های شخص ثالث

Wallex

منبع قیمت‌های عمومی بازار است. درخواست‌های افزونه به سرورهای Wallex می‌رسد و پردازش آن‌ها تابع سیاست حریم خصوصی خود Wallex است. تترچند کنترلی بر داده‌هایی که Wallex نگه می‌دارد ندارد.

GitHub

برای ارتباط و گزارش مشکل از GitHub Issues استفاده می‌کنیم. هر محتوایی که در GitHub منتشر می‌کنید تابع سیاست حریم خصوصی GitHub است.

ارتباط با ما

برای پرسش، گزارش مشکل یا درخواست مربوط به حریم خصوصی، از طریق GitHub Issues با ما در ارتباط باشید. لطفاً اطلاعات حساس یا خصوصی را در Issues عمومی منتشر نکنید.
